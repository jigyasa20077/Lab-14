Day 14 — Capstone GenAI Workflow Portfolio

Day 14 brought together the major concepts learned throughout the Generative AI course into an end-to-end aviation-management capstone. The workflow covered Business Brief → Tool Selection → Prompt Design → Content Generation → Human Review → Source Verification → Final Output. Students were required to define an aviation business problem, select appropriate AI tools, create and refine prompts, generate workplace and visual outputs, and review them for accuracy, tone, compliance, context and privacy. The capstone also included hallucination and privacy audits, source verification, severity × risk assessment, a final presentation and a structured GitHub portfolio. The main learning was that Generative AI can support aviation-business work effectively, but human judgement and verification remain essential throughout the workflow.
